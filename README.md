# awesome-football

A curated list of awesome football (soccer) resources: analytics, predictions, statistics and data tools.

## Predictions & Analytics

- [Footalytics](https://footalytics.farvor.com) - AI football match predictions with win/draw/loss probabilities, confidence tiers, over/under 2.5 goals, BTTS, team ratings and a public graded accuracy ledger for the top leagues.
